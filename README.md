# 🎮 so_long

**so_long** is a simple 2D graphical game developed in C using the **MiniLibX** library. The project was created as part of the **42 Network** curriculum to introduce basic graphics programming, event handling, and map parsing.

---

## 🧠 Project Goal

The goal of this project is to create a small 2D game where a player can move through a map, collect items, and reach the exit while avoiding walls. This project teaches:

- Basic game loop structure
- Window and image rendering
- User input handling (keyboard events)
- File parsing and validation

---

## 🕹️ Gameplay Overview

- The game reads a `.ber` map file.
- The player moves with `W`, `A`, `S`, `D`.
- The objective is to collect all collectibles (`C`) and reach the exit (`E`).
- The player (`P`) cannot pass through walls (`1`).
- Floors are marked as `0`.
